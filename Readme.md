# FilaSmart

Sistema web inteligente de gestion de filas y tiempos de atencion

# Descripcion

FilaSmart es una plataforma web orientada a establecimientos (pequeños y medianos) que gestionan la atencion de clientes por orden de llegada al local

El proyecto busca permitir la gestion virtual de filas y turnos, entregando informacion sobre la posicion y el tiempo aproximado de espera para cada cliente que desea ser atendido
