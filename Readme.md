# FilaSmart

Sistema web inteligente de gestion de filas y tiempos de atencion.

## Descripcion

FilaSmart es una plataforma web orientada a establecimientos que gestionan la atencion de clientes por orden de llegada.

El proyecto busca permitir la gestion virtual de filas y turnos, entregando informacion sobre la posicion y el tiempo aproximado de espera.

Actualmente se encuentra en la etapa inicial de planificacion y desarrollo.
